OUR PROJECT

We built this site to showcase our skills.

This website was improved for our Front-End Assignment #3 project at Astana IT University. We developed the fictional studio concept further by adding CSS media queries and Bootstrap responsive components.

Our goal was to extend the same design with responsive typography, the Bootstrap grid, navigation, buttons, cards, a carousel and accessible form controls.
